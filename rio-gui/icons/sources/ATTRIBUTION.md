# Icon attribution

The artwork in this folder comes from [Flaticon](https://www.flaticon.com/) under its
free licence, which **requires** the author to be credited wherever the icon is used.
This file is that credit, kept beside the files themselves so the two cannot be
separated; the same credits appear in [PITCH.md](../../../PITCH.md).

The credit lines below are the exact form Flaticon asks for.

---

**Adding an icon?** Put its credit here in the same form, in the same commit that adds
the file. Every artwork in this folder needs one whether or not it is the active icon —
they all ship in the repository, and `icons/active` decides only which one rio wears.
The cut `rio-*.png` files one level up inherit the credit of the source they came from.
